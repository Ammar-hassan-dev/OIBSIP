## Description
A GUI-based random password generator built with Python's Tkinter library. Users can select the desired password length and choose which character types to include (uppercase, lowercase, digits, symbols), then generate a strong random password with a single click.

## Features
- Adjustable password length via slider (4-32 characters)
- Customizable character sets: uppercase, lowercase, digits, symbols
- One-click password generation
- Copy to clipboard functionality
- Clean, professional card-style GUI

## Tech Stack
- Python 3
- Tkinter (built-in GUI library)
- `random` and `string` modules (built-in)

## How to Run
1. Make sure Python 3 is installed.
2. Open this folder in terminal.
3. Run:
   ```
   python password_generator.py
   ```
4. Adjust the length slider, select character types, and click "Generate Password".
