## Description
A simple and interactive BMI (Body Mass Index) Calculator built using Python's built-in Tkinter library. The app takes a user's weight (in kg) and height (in meters), calculates their BMI, and displays the result along with the corresponding health category.

## Features
- Clean and simple graphical user interface (GUI)
- Real-time BMI calculation
- Categorizes result into: Underweight, Normal weight, Overweight, Obese
- Input validation (handles empty/invalid/negative values)
- Reset button to clear fields and start over
- Color-coded result for quick visual feedback

## Tech Stack
- Python 3
- Tkinter (built-in GUI library, no extra installation required)

## How to Run
1. Make sure Python 3 is installed.
2. Open this folder in terminal.
3. Run: python bmi_calculator.py
4. Enter your weight (kg) and height (m), then click Calculate BMI.

## BMI Categories Used
| BMI Range | Category |
|-----------|----------|
| Below 18.5 | Underweight |
| 18.5 - 24.9 | Normal weight |
| 25.0 - 29.9 | Overweight |
| 30.0 and above | Obese |
